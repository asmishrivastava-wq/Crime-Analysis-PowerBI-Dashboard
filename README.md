········# Crime Analysis Power BI Dashboard

## Project Overview

This project was developed as part of my Power BI training at CRISP, Bhopal.

The dashboard analyzes crime data to identify trends, patterns, and key performance indicators through interactive visualizations. The objective is to support data-driven decision-making by presenting crime statistics in a clear and insightful manner.

---

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Dataset

The project uses a crime dataset containing incident-related information for analytical reporting and visualization.
